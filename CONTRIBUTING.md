# Contributing to SCR Mailer

Report bugs and propose changes in [Sites Computer Resources' repository](https://github.com/sitescomputer/SCR-Mailer/issues). Include the SCR release, steps to reproduce, and relevant logs without secrets.

Keep functional changes separate from branding where practical. Run the frontend build, Go tests and a backend build before submitting a pull request. Upstream integration pull requests must preserve merge ancestry; see [the update guide](docs/UPSTREAM-UPDATES.md).

This fork retains upstream compatibility identifiers and license notices. See [UPSTREAM.md](UPSTREAM.md).
