# Security reports

For a vulnerability in SCR Mailer, use [GitHub private vulnerability reporting](https://github.com/sitescomputer/SCR-Mailer/security/advisories/new) if it is enabled for the repository. Avoid posting credentials, subscriber data, or exploit details in a public issue.

The original listmonk project has its own [security policy](https://github.com/knadh/listmonk/security/policy). Report issues in third-party components to their respective maintainers.
